🏥 Clinic Management System

A full-stack web application for managing clinic operations including appointments, doctor schedules, and electronic prescriptions.

🚀 Features
Patient registration & login
Online appointment booking with queue number
Reception can add unlimited bookings
Admin dashboard to manage doctors, services, and schedules
Doctor dashboard to view appointments and write prescriptions
Patients can view appointments and prescriptions

🧠 Core Concepts
Queue System: Each patient gets a unique queue number per day
Doctor Schedule: Controls working hours & max patients
Online Booking Limit: Controlled by admin
Electronic Prescription: Doctors select medicines from a predefined list
